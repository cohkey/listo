# Listo アプリ構成

## 共有するもの

`../docs` が唯一の画面ソースです。Web版、macOS版、iPhone版でHTML・CSS・JavaScriptを複製しません。

iPhoneの日常利用はGitHub Pagesから読み込むホーム画面版です。App Store配布は使いません。Service Workerは画面ファイルだけをキャッシュし、タスクは従来どおり各端末のLocal StorageとSupabaseへ保存します。

## 保存レイヤー

1. ローカル保存: すべての変更を即時保存し、オフライン動作を維持します。
2. 同期待ちキュー: クラウドへ未送信の最新スナップショットを保持します。
3. Supabase: ログインしたユーザーごとに1つの暗号化通信済みスナップショットを保存します。
4. JSONバックアップ: ユーザー操作で作成する独立した復元ファイルです。

## セキュリティ

- ブラウザへ置くのはPublishable / Anon keyだけです。
- RLSにより、ログインユーザーは自分の行だけを読み書きできます。
- パスワードはListoの保存領域へ保存しません。
- セッションは各端末のローカル領域へ保存します。
- TauriのCSPはSupabase、Google Fonts、自身のアセット以外への接続を許可しません。

## 競合方針

初期版は個人利用を前提に、端末の更新時刻を使ったLast Write Winsです。複数人による同時編集が必要になった場合は、タスク単位の更新時刻と削除履歴へ拡張します。
