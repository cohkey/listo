# Listo テスト手順

このファイルは、機能追加や不具合修正のたびに確認する内容を記録するものです。

## 自動テスト

`docs` フォルダで次を実行します。

```powershell
node --check task-core.js
node --check todoist-import.js
node --check script.js
node --check sync-core.js
node --check sync.js
node --check sync-config.js
node --check pwa.js
node --check service-worker.js
node --test task-core.test.js todoist-import.test.js sync-core.test.js ui-contract.test.js
git diff --check
```

### `task-core.test.js` で確認すること

- 旧データの読み込みとデータ形式の補正
- プロジェクト、タグ、優先度、期限、ステータスの処理
- プロジェクト削除時の未分類への移動と、タグの追加・名称変更・削除
- 2条件の並び替えと各種グルーピング
- リストとテーブルのプロジェクト・タグ・優先度グルーピング
- 期限切れ・今日・明日・今後7日の判定と期限文言
- ステータス、優先度、プロジェクト、タグ、工数、完了推移の集計
- 保存フィルターと「今日・明日・今後7日」などの期限条件
- 繰り返しタスク、サブタスク、工数、時間計測
- CSVの解析・取込・出力とJSONバックアップの往復
- CSV全文とExcelコピーのタブ区切り貼り付け取込
- 不正値、空文字、重複データを安全に扱えること

### `ui-contract.test.js` で確認すること

- JavaScriptが参照する画面要素がHTMLに存在すること
- ボタン、入力欄、ダイアログの役割と閉じ方
- リスト、テーブル、カンバン、タイムライン、近日予定カレンダーの表示契約
- プロジェクト、お気に入り、保存フィルター、ゴミ箱の操作入口
- タグ管理画面、プロジェクト削除、アプリアイコンとファビコンの参照
- ライト・ダーク・スマートフォン用CSSと、非表示要素が残らないこと
- CSV・JSON操作とWindows向けキーボードショートカット
- Web版の構成を保ったまま、同期設定画面とオフライン同期処理が接続されていること
- iPhoneのセーフエリアを考慮した余白が定義されていること

### `sync-core.test.js` で確認すること

- ローカルにだけ変更がある場合はクラウドへ送ること
- クラウドにだけデータがある場合は端末へ取り込むこと
- ローカルとクラウドのうち、更新時刻が新しい方を採用すること
- 壊れた同期データを読み込んでもアプリを停止させないこと
- アクセストークンと更新トークンを保存し、有効期限前に自動更新できること
- 登録済み、確認メール未完了、通信失敗を分かりやすい日本語で案内すること

### `todoist-import.test.js` で確認すること

- TodoistのプロジェクトCSV名からプロジェクト名と内部IDを分離すること
- `TYPE=task`だけを取り込み、メタ情報とリマインダーを除外すること
- Todoistの優先度、`@ラベル`、日本語の期限・繰り返しをListo形式へ変換すること
- インデントされた子タスクと説明文をListoのサブタスクとして保持すること
- 日本語名を含むZIPから複数CSVを安全に展開できること
- 複数プロジェクトの件数と警告を正しく集約すること

## Macアプリ自動テスト

リポジトリ直下で次を実行します。

```powershell
node --test desktop/tauri-contract.test.js
cd desktop
npm install
npm run tauri -- info
cargo check --manifest-path src-tauri/Cargo.toml
npm run build
```

`tauri-contract.test.js` では、Mac・iPhone版がWeb版と同じ `docs` フォルダーを参照すること、アプリID、対応OS、Supabaseの通信許可などを確認します。`npm run build` は実際にMac用アプリを生成する確認です。

iPhone用の `npm run ios:init` と `npm run ios:build` は、フル版XcodeとAppleの開発用ツールが利用できるMacで実行します。

## ブラウザ操作テスト

自動テスト後、ローカル確認用サーバーで画面を開き、次を実際に操作します。確認用データは通常利用中の `file://` 版と分け、`localhost` 側で扱います。

1. 「すべて」でページを上下へ動かし、サイドバー内も先頭からデータ操作までスクロールできる。
2. タスクが0件のプロジェクトを開き、空表示だけが出て、追加したタスクへ表示中のプロジェクトが付く。
3. 保存フィルターの期限で「明日」を選び、明日のタスクだけになる。
4. 今日・すべて・完了で、プロジェクト別・タグ別・優先度別・グループなしを切り替える。
5. タスク詳細を開き、背景・×・キャンセル・Escで安全に閉じられる。
6. 時間計測を開始・停止し、秒表示と実績時間への加算を確認する。
7. 近日予定で前週・今日・次週へ移動し、タスク詳細を開ける。
8. プロジェクトのお気に入り登録・解除と、サイドバー上部への表示を確認する。
9. ライト・ダークの両方で文字、タスク、タグ、期限の色が読める。
10. 開発者コンソールにJavaScriptエラーがない。
11. 期限サマリーの4区分が重複せず、タスクの期限文言と強調色が一致する。
12. レポートでステータス円グラフ、優先度・プロジェクト・タグの棒グラフ、工数、直近7日の完了グラフが表示される。
13. タスクがあるプロジェクトを削除すると確認が出て、タスクが「未分類」へ移り、お気に入りと保存フィルターも整理される。
14. タグ管理で未使用タグの追加、使用中タグの名称変更と削除を行い、タスク詳細と保存フィルターへ反映される。
15. 近日予定カレンダーで完了タスクがチェック、取り消し線、完了色で区別され、詳細を開ける。
16. プロジェクトを開くと期限サマリーがそのプロジェクトだけの件数になり、「すべて」へ戻ると全体件数へ戻る。
17. ブラウザータブにファビコンが表示され、インストール用マニフェストから192px・512pxのアイコンを読み込める。
18. テーブル表示でプロジェクト別・タグ別・優先度別・グループなしを切り替え、各見出しと件数が正しい。
19. クイック追加欄でプラスの飾りがなく、入力・Enter追加・詳細追加の役割が迷わず判別できる。
20. 「CSV貼付」でカンマ区切りCSVとExcelからコピーしたタブ区切り表を貼り、プレビュー・列割り当て・重複判定を経て取り込める。
21. Windows Edge相当の画面幅で、サイドバーに横スクロールが出ず、縦スクロールがボタンへ重ならない。グループテーブルの横スクロールは1本だけで、右端の「詳細」が常に押せる。
22. テーブルの完了ボタンが未完了時は丸い輪、完了時は緑のチェックとして表示され、ホバー・キーボードフォーカス・ダークモードでも状態を判別できる。
23. タスクがあるプロジェクトを開き、リスト・テーブルの両方でタグ別・優先度別・グループなしを切り替え、表示中プロジェクトのタスクだけが正しくグループ化される。
24. 1920px幅で通常リストが過度に中央へ寄らず左側から始まり、テーブル・カンバン・タイムライン・近日予定カレンダーが本文領域の横幅をほぼ全面利用する。760px以下では従来どおり左右16pxの余白になる。
25. 未完了と完了が混在するプロジェクトを開き、進捗率が「完了数 ÷ そのプロジェクトの全タスク数」で表示され、別プロジェクトや今日のタスクが混ざらない。
26. テーブルで長いタスク名が折り返され、文字数に合わせて行の高さも伸び、途中で見切れない。Enterで編集を確定でき、マウスを重ねると全文も確認できる。
27. サイドバーの「iPhoneと同期」から設定画面を開き、×・Esc・背景クリックで閉じられる。
28. 同期未設定で「この端末だけで保存中」と表示され、タスクの追加・編集・再読み込みが従来どおり動作する。
29. 不正なProject URL、短すぎるキー、`service_role`、secret keyを保存できない。
30. テスト用Supabaseでログイン後、端末Aでの変更が端末Bに反映され、逆方向の変更も反映される。
31. オフライン中に変更すると「同期待ち」になり、オンライン復帰後に自動で同期済みになる。
32. 390px幅で同期画面を開き、上下のセーフエリアと操作ボタンが重ならない。
33. 新しい濃紺のアイコンがMacで角丸・外側透過になり、iPhoneホーム画面ではOSの角丸マスクが正常に適用される。
34. Macの同期設定からiPhone用リンクを作成し、iPhoneで開くとProject URLと公開用キーだけが取り込まれる。
35. iPhoneのSafariからホーム画面に追加し、スタンドアロン表示、再起動、オフライン時の画面起動を確認する。
36. 初回はMidnightテーマで表示され、サイドバー・追加欄・リスト・テーブル・カンバン・タイムライン・カレンダー・レポート・各ダイアログが濃紺／シアン／インディゴの同じデザイン言語で統一される。ライト切替後も寒色系の配色を保つ。
37. 同期画面の「同期を準備 → アカウント → iPhoneで開く」が、接続設定とログイン状態に合わせて現在・完了・未着手へ切り替わる。
38. 接続済みの場合は技術設定が自動で折り畳まれ、iPhoneへのリンク送信と「ホーム画面に追加」の案内が迷わず見つかる。
39. 同期アカウントで「アカウントを作成」を押すと、ボタンが「作成中…」に変わり、成功・確認メール待ち・失敗の結果が入力欄の直下に表示される。
40. ログイン後にページを再読み込み、アプリを再起動してもログイン表示と自動同期が維持される。アクセストークンの期限後は更新トークンで自動復帰する。
41. 「Todoist移行」でTodoistバックアップZIPを選び、プロジェクト数・タスク数・サブタスク数・確認事項が表示される。
42. Todoist移行のプレビューでプロジェクト、優先度、期限、繰り返し、タグが元CSVどおり変換され、取り込み前にはListoの既存タスクが変わらない。
43. Todoist移行を確定すると既存データを残したまま追加され、同じタスクを再度取り込んだ場合は既定で重複がスキップされる。
44. ZIPを展開した複数CSVをまとめて選択しても、ファイル名ごとに別プロジェクトとして取り込まれる。
45. 「すべて」で期限が今日・明日・未設定のタスクをそれぞれ「今日やる」へ追加し、期限に関係なく「今日やること」へ表示される。
46. リスト・テーブル・カンバン・詳細画面から「今日やる」を追加・解除でき、再読み込みとJSONバックアップ・同期後も状態が残る。
47. サイドバーのバージョンを押すと更新履歴が開き、×・閉じる・背景クリックで閉じられる。
48. プロジェクト削除の確定ボタンがライト・ダークの両方で危険操作として判別でき、キャンセルは従来どおり安全に閉じる。
49. プロジェクト行の鉛筆ボタンから名称を変更すると、タスク、お気に入り、保存フィルター、ゴミ箱内のタスクへ反映される。
50. 「未分類」、空文字、既存プロジェクトと同じ名前への変更は拒否され、元データが維持される。
51. ログイン済みの端末では再読み込み時にセッションを復元し、画面復帰・オンライン復帰・フォーカス時に手動操作なしで同期する。
52. セッション更新が重なっても同じ更新処理を共有し、Supabaseの更新トークンを同時に複数回使用しない。
53. iPhone 17相当を含む幅393px・402px・430pxで、長いタスク名と期限・プロジェクト・状態・優先度・繰り返し・タグが画面外へはみ出さず折り返される。
54. iPhone幅では今日・時間計測・編集操作が本文を圧迫せず、各ボタンをタップできる。
55. ホーム画面版ではDynamic Islandと画面下端の安全領域に見出し・操作が重ならない。
56. テーブル・カンバン・タイムライン・カレンダーの横長コンテンツはページ全体ではなく各表示内だけで横スクロールする。

## 変更時のルール

- 共通処理を変更したら `task-core.test.js` に正常系と境界値を追加します。
- HTML、CSS、操作入口を変更したら `ui-contract.test.js` を更新します。
- 同期の判定ロジックを変更したら `sync-core.test.js` を更新します。
- Mac・iPhoneラッパーの設定を変更したら `desktop/tauri-contract.test.js` を更新します。
- スクロール、フォーカス、ドラッグ、ダイアログなど画面操作に関わる変更は、ブラウザでも確認します。
- テストがすべて成功してからコミットし、プルリクへ反映します。
