# Listo 更新履歴

アプリ内の「Listo v… → 更新履歴」と同じ要点を、リポジトリでも確認できるように残します。

## v0.2.3 - 2026-10

- iPhone幅ではタスクの操作を2段目へ配置し、タイトルと属性を画面内で折り返し
- Dynamic Islandとホーム画面版の上下左右の安全領域に対応
- テーブル、カンバン、タイムライン、カレンダーの横スクロールを各表示内に限定

## v0.2.2 - 2026-10

- iPhoneに保存したログイン状態を起動時に自動復元
- オンライン復帰、画面フォーカス、バックグラウンドからの再表示時に自動同期
- 同時に複数のトークン更新が走らないようセッション更新を直列化

## v0.2.1 - 2026-10

- サイドバーの鉛筆ボタンからプロジェクト名を変更可能に
- 変更した名称をタスク、お気に入り、保存フィルター、ゴミ箱内のタスクへ一括反映
- 重複名と「未分類」の変更を防ぐ入力チェックを追加

## v0.2.0 - 2026-10

- 期限とは別に、自分で選べる「今日やる」リストを追加
- TodoistバックアップZIP・CSVからの移行に対応
- プロジェクト削除の確認と危険操作の表示を改善
- アプリ内の更新履歴とバージョン表示を追加

## v0.1.5

- Mac・Web・iPhoneのSupabase同期、ログイン維持、iPhone共有を追加
- ダークテーマとアプリアイコンを刷新

## v0.1.4

- 期限サマリー、レポート、グラフ、完了状態つきカレンダーを追加

## v0.1.3

- プロジェクト、タグ、サブタスク、時間計測、お気に入り、保存フィルターを追加

## v0.1.2

- テーブル、カンバン、タイムライン、近日予定、CSV・JSON入出力を追加

## v0.1.0

- リスト、優先度、期限、ローカル自動保存を備えた初期版
